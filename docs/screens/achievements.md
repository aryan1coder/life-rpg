# Screen Specification: Achievements & Accolades (`/achievements`)

## 1. Purpose & User Story
Permanent milestone recognition system tracking lifetime disciplined operating velocity across execution, consistency, and mastery domains.

## 2. Component Hierarchy
- `MasterCompletionCard`: Global progress percentage (12/30 Unlocked · 40%).
- `PriorityTrackCard`: Active focus on current target accolade (*Consistency Legend* · 14/21 Days).
- `AccoladeMatrix`: Responsive grid displaying cards across three distinct states:
  - *Unlocked:* Solid emerald check badge, date unlocked, claimed yield.
  - *In Progress:* Electric indigo progress bar with exact ratio.
  - *Locked:* Muted dark card with clear prerequisite criteria.
