# Screen Specification: Character & Progression (`/character`)

## 1. Purpose & User Story
Deep character progression studio and career evolution chronicle. Reflects lifetime stats, equipped cosmetic loadouts, attribute trend lines, and career milestones.

## 2. Component Hierarchy
- `HeroIdentityCard`: High-resolution cybernetic avatar portrait with ambient indigo glow, rank badge, and level indicator.
- `AttributeCapacityEngine`: 5 attributes (INT, DIS, VIT, STR, CRE) with 7-day sparkline charts and historical gain ledgers.
- `EvolutionChronicle`: Vertical career path showing unlocked operating subroutines from Level 1 to current tier.
- `ActiveEquippedTitle`: Selector allowing instant switching of operator titles.
